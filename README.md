# taller_09-G2
Desarrollar competencias para diseñar, implementar y probar mecanismos de comunicación síncrona y asíncrona entre microservicios, mediante el uso de Spring Boot, API REST, RabbitMQ y Postman, aplicándolos al proyecto de curso para comprender sus implicaciones en el acoplamiento, la interoperabilidad, la resiliencia y la escalabilidad de una arquitectura basada en microservicios.
